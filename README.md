## ✦ What is ArcadeX?

> ArcadeX is a handcrafted, zero-dependency browser arcade built entirely with **Vanilla JavaScript**, **HTML5 Canvas**, and cutting-edge **CSS3**. Every pixel glows with glassmorphism panels, neon effects, and fluid animations — all without touching a single npm package.

It's not just a game collection. It's a love letter to raw web development.

## ✦ Tech Stack

<div align="center">

| Layer | Technology | Details |
|---|---|---|
| 🧠 Logic | Vanilla JavaScript (ES6+) | Custom events, modular game scripts |
| 🎨 Styling | CSS3 | Glassmorphism, neon glow, `backdrop-filter` |
| 🖼️ Rendering | HTML5 Canvas API | Snake game real-time rendering |
| 🔤 Typography | Outfit + Pixelify Sans | Google Fonts — pixel-perfect character |
| 📦 Dependencies | **None** | Pure web — no React, no npm, no build step |

## ✦ Getting Started

No build step. No installation. Just open and play.

```bash
# Clone the repository
git clone https://github.com/your-username/ArcadeX.git

# Navigate into the folder
cd ArcadeX

# Open in browser (or serve locally)
open index.html
```

> **Tip:** For the best experience, serve from a local server to avoid CORS quirks with font loading.
>
> ```bash
> # Using Python
> python3 -m http.server 8000
>
> # Using Node.js (npx)
> npx serve .
> ```

## ✦ Design Philosophy

ArcadeX was built on one rule:

> *"If it can be done in CSS, it should be done in CSS."*

The visual identity — the `#050510` void, the purple/cyan neon duality, the glass panels — was designed to feel like a **premium arcade cabinet from a retrofuture that never existed**. Every hover, every glow, every animation exists to make the player feel like they've entered another world.
